# Скриншоти кейсів для 3D-прелоадера

Зараз прелоадер використовує зображення кейсів із `site/images/` — ті самі, що на сайті.
Щоб показувати спеціально підготовлені кадри, покладіть файли сюди й пропишіть шляхи
в масиві `CASES` на початку `site/js/preloader.js`.

## Формат файлів

| Параметр | Значення |
|---|---|
| Формат | WebP (пріоритет) або AVIF |
| Розмір по довшій стороні | 1200–1600 px, не більше |
| Вага одного файлу | до 250 КБ |
| Пропорції | `desktop` — квадрат 1:1 або 16:10; `secondary` — 1:1 або вертикаль 3:4 |

Не кладіть сюди оригінальні скриншоти по 5–10 МБ: усі зображення завантажуються
до старту анімації, тож вага напряму додається до часу очікування.

## Іменування

```
project-1-desktop.webp     головний екран сайту (центральна площина)
project-1-secondary.webp   мобільна версія / інший блок / деталь (бічні площини)
```

## Приклад конфігурації

```js
const CASES = [
  {
    title: "Project name",
    desktop: "assets/cases/project-1-desktop.webp",
    secondary: "assets/cases/project-1-secondary.webp"
  }
];
```

Поле `secondary` необов'язкове. Якщо його немає (`null`), на нижній і верхній
площинах показується кадрований фрагмент основного зображення — композиція
лишається цілісною без додаткових файлів.

## Скільки кейсів

Оптимально 5–7. На мобільних автоматично показуються перші 4 — решта не
завантажується взагалі, щоб не витрачати трафік.

## Конвертація

```bash
# з PNG/JPG у WebP потрібного розміру
cwebp -q 82 -resize 1400 0 screenshot.png -o project-1-desktop.webp
```
