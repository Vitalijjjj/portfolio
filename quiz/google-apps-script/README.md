# Запис відповідей квіза в Google-таблицю

Квіз пише кожну відповідь у таблицю **одразу** (навіть якщо людина не
натиснула «Надіслати») — один рядок на респондента, який поступово
заповнюється. Реалізовано через Google Apps Script, розгорнутий як веб-застосунок.

Таблиця: https://docs.google.com/spreadsheets/d/1NJ3K7pxehYSrUoRd1rrGZvPGl297ksajKB-nsi4OZMc/edit

## Як розгорнути (одноразово, ~2 хв)

1. Відкрийте таблицю → меню **Розширення → Apps Script**.
2. Видаліть увесь код у файлі, вставте вміст [Code.gs](Code.gs), збережіть (Ctrl/Cmd+S).
3. Праворуч угорі **Deploy → New deployment**.
4. Шестерня **⚙ (Select type) → Web app**.
5. Налаштування:
   - **Description**: `quiz`
   - **Execute as**: **Me** (ваш акаунт — щоб мати право писати в таблицю)
   - **Who has access**: **Anyone**
6. **Deploy** → погодьтесь із дозволами (Google попросить авторизацію — це
   нормально, скрипт пише лише у вашу таблицю).
7. Скопіюйте **Web app URL** (закінчується на `/exec`) і надішліть його мені —
   я пропишу його у змінну `GOOGLE_SHEET_WEBAPP_URL` на Vercel і задеплою.

Готово: у таблиці зʼявиться аркуш **«Відповіді»** із заголовками, і рядки
почнуть заповнюватися в реальному часі. Стовпець **Статус** показує
`В процесі` (людина ще проходить) або `Завершено` (натиснула «Надіслати»).

## Якщо зміните питання у квізі

Синхронізуйте масив `FIELDS` у [Code.gs](Code.gs) з ключами кроків у
`quiz/quiz.js` (`STEPS[].key`), збережіть і зробіть **Deploy → Manage
deployments → Edit → Deploy** (новий версійний деплой на той самий URL).
